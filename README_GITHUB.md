# Travel Expense Voucher Document Builder

GitHub-ready web application scaffold.

## Repository upload
Upload all files in this folder to one GitHub repository.

## Local test
1. Install Python 3.
2. `pip install -r requirements.txt`
3. `python app.py`
4. Open `http://127.0.0.1:8000`

## Online deployment
This repository includes `render.yaml` and a `Procfile` for a Python web service.

## Current status
The existing TEV interface is included. The backend upload endpoint is ready.
The next integration is server-side OCR for scanned BSWM Travel Orders and editable Excel generation from the included master templates.
