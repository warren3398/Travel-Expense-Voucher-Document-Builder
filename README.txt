TEV DOCUMENT BUILDER — GitHub Pages Manual TO v1.4

This version uses MANUAL TRAVEL ORDER ENTRY.
No OCR, AI document reading, Python, Tesseract, server, or CMD is required.

WORKFLOW
1. Open the GitHub Pages site.
2. Fill out Travel Order Details ONCE.
3. Click Save Travel Order Details.
4. The saved TO information becomes the master data for the TEV forms.
5. Complete only the form-specific fields such as Fund Cluster, TIN/ID,
   itinerary expenses, CNRR entries, accomplishment details, etc.

TO MASTER FIELDS
- TO Number
- Employee/Payee
- Position
- Departure Date
- Return Date
- Destination
- Purpose
- Objective

GITHUB PAGES
Upload all files inside this extracted folder to the repository root.
Settings > Pages > Deploy from a branch > main > /(root).
